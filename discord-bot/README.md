# ☭ Бот сервера «СССР РП»

Бот одной командой настраивает Discord-сервер для мобильной RP-игры «СССР РП» (Казань, Пятигорск, Бусаево):
он создаёт 31 роль, 22 категории и 103 канала, расставляет права, публикует правила и шаблоны, добавляет кнопки
и включает автомодерацию. После настройки бот продолжает работать на сервере: проводит верификацию, открывает
тикеты, принимает заявки, ведёт логи и модерацию.

Полная структура со всеми текстами описана в **[STRUCTURE.md](STRUCTURE.md)**.

## Что делает бот

| Функция | Как работает |
|---|---|
| **Верификация** | Кнопка в #верификация → игрок вводит игровой ник → бот меняет ник на сервере, снимает «Новичок», выдаёт «Гражданин», приветствует в #общий-чат |
| **Автороль** | При входе выдаёт «Новичок» (ботам — «Боты») и напоминает в #верификация пройти проверку (это сообщение удаляется через 10 минут) |
| **Тикеты** | Меню в #создать-тикет: жалоба, баг, вопрос, заявка, жалоба на администрацию. Бот создаёт закрытый канал, который видят автор и администрация. Жалобу на администрацию видят только Главный администратор и Основатель |
| **Заявки** | Меню в #заявки-в-организации → форма из 5 полей → заявка появляется с кнопками ✅/❌. Нажать их могут лидер этой организации или администрация. При ✅ бот сам выдаёт роль и пишет в #кадры организации. Так же работают заявки на лидерство, в администрацию и в тестеры |
| **Лидеры** | `/принять` и `/уволить` — лидер выдаёт и снимает роль **только своей** организации; права на роли всего сервера ему не нужны |
| **Модерация** | `/пред`, `/преды`, `/снять-пред`, `/мут`, `/размут`, `/кик`, `/бан`, `/разбан`. Всё записывается в #логи-наказаний. **3 предупреждения = бан на 3 дня** (снимается автоматически) |
| **Автомодерация** | В общих каналах бот удаляет мат и капс. Встроенная автомодерация Discord блокирует спам, приглашения на чужие серверы и массовые упоминания |
| **Логи** | В #логи-сервера: вход и выход, удалённые и изменённые сообщения, смена ролей и ников, тикеты |
| **Предложения** | Под каждой идеей в #предложения бот ставит 👍 и 👎 |

## Запуск по шагам

### 1. Создайте сервер и бота
1. Создайте пустой сервер в Discord.
2. Откройте https://discord.com/developers/applications → **New Application** → назовите, например «СССР РП».
3. Раздел **Bot**:
   - **Reset Token** → скопируйте токен. **Никому его не показывайте.**
   - Включите **SERVER MEMBERS INTENT** и **MESSAGE CONTENT INTENT**.
4. Раздел **OAuth2 → URL Generator**: отметьте `bot` и `applications.commands`, в правах — **Administrator**.
   Откройте полученную ссылку и добавьте бота на свой сервер.

### 2. Узнайте ID сервера
Discord → Настройки → Расширенные → включите **Режим разработчика**. Затем нажмите правой кнопкой
(на телефоне — долгое нажатие) на сервер → **Копировать ID сервера**.

### 3. Запустите бота
Нужен Python 3.10 или новее.
```bash
cd discord-bot
pip install -r requirements.txt
cp .env.example .env        # впишите в .env DISCORD_TOKEN и GUILD_ID
python bot.py
```

### 4. Настройте сервер
1. **Настройки сервера → Роли**: перетащите роль бота на **самый верх** списка.
2. В любом канале напишите **`/настроить-сервер`** (может только владелец сервера или «Основатель»).
   Настройка займёт несколько минут: Discord ограничивает скорость создания каналов.
3. Выдайте себе роль **Основатель**.
4. Удалите стандартные каналы Discord (#general и т. п.), если они не нужны.

Команду можно запускать повторно: бот ничего не дублирует, а только обновляет права и тексты и создаёт
недостающее. Если настройка прервалась, просто запустите её снова.

### 5. Что сделать вручную
- Вставьте ссылку на APK в `texts.py` (`APK_LINK`) и снова выполните `/настроить-сервер`.
- Загрузите иконку и баннер сервера в красно-золотом стиле.
- По желанию включите **«Сообщество»** (Community) в настройках сервера. Тогда #новости можно сделать
  каналом объявлений, на который подписываются другие серверы.
- Лидеры заменяют заглушки в каналах #устав-… своими уставами.
- Уровни активности бот не считает. Если они нужны, добавьте MEE6 и выдайте ему роль «Боты».

## Бот должен работать постоянно
Верификация, тикеты, заявки и модерация работают, только пока бот запущен. Варианты:
- свой компьютер (бот работает, пока компьютер включён);
- VPS за 150–300 ₽ в месяц;
- бесплатные хостинги для Discord-ботов.

Файл `data.json` хранит предупреждения, муты, тикеты и ID каналов. При переносе бота на другую машину
переносите его тоже.

## Как изменить структуру
- **`config.py`** — роли, цвета, права, категории, каналы, тикеты, слова для фильтра мата.
- **`texts.py`** — правила, шаблоны, приветствия и формы заявок.

После изменений проверьте файлы и обновите документацию:
```bash
python bot.py --check                # проверка без подключения к Discord
python bot.py --docs > STRUCTURE.md  # пересобрать описание структуры
```
Затем снова выполните `/настроить-сервер` на сервере.

## Права коротко
- **@everyone / Новичок** видят только 📌 ИНФОРМАЦИЯ и ✅ ВЕРИФИКАЦИЯ.
- **Гражданин** видит общение, поддержку, заявки и #приём-граждан мэрии.
- **Категории организаций и ОПГ** видят только свои члены, их лидер и администрация. #оперативные-данные КГБ
  модераторы не видят.
- **Лидеры** управляют каналами своей категории и закрепляют сообщения; ролями сервера они не управляют.
- В информационные каналы пишут только Главный администратор и Администратор. Основатель видит и может всё.
- Добавлена категория **🧪 ТЕСТИРОВАНИЕ** для роли «Разработчик / Тестер»: #тестовые-сборки, #баги-тестеров,
  #чат-тестеров и голосовой канал.
